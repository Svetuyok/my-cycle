Мой цикл — PWA
Загрузите все файлы из этой папки в корень HTTPS-хостинга.
Данные приложения хранятся локально на устройстве.
Перед удалением приложения/очисткой Safari/сменой телефона делайте экспорт резервной копии.
Фоновые запланированные push-уведомления в полностью локальной версии не гарантируются; календарные подсказки показываются при открытии приложения.
